# HydroRecycle India — Vercel Ready

This version is a static web app. It does not require Python or a server at runtime.
All dashboard and hydraulic calculations run in the browser, making it simple to deploy on Vercel.

## Deploy
1. Extract this folder.
2. Put the folder in a GitHub repository.
3. In Vercel, import that repository.
4. Framework preset: Other.
5. Build command: leave empty.
6. Output directory: leave empty / root.
7. Deploy.

The resulting public URL can be opened from the exhibition laptop or phone.

## Data integrity
The state waste columns are source-based 2021–22 educational data.
Columns marked with * in the UI are simulated educational placeholders and should be replaced by your actual repeated model measurements before being presented as experimental findings.
